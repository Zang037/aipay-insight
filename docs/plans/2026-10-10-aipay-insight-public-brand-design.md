# AI Pay Insight 公开品牌设计

## 目标

将仓库的公开身份从上游项目品牌切换为独立的 `aipay-insight`：GitHub 展示名使用“AI支付洞察”，英文使用“AI Pay Insight”，站内产品名继续使用“AI支付”。

## 公开文案

- 仓库名：`aipay-insight`
- 中文名：AI支付洞察
- 英文名：AI Pay Insight
- 简介：全球 AI 产品与 AI支付创新雷达：追踪新品、公测与重要更新，提炼可迁移到 AI支付的交互、授权、信任和商业模式。

## 修改范围

1. 重写根目录中英文 README，移除上游横幅、品牌口号、线上原站和社区入口。
2. README 只描述当前 AI支付站的目标、信源、编辑标准、运行方式和验证状态。
3. 保留 MIT 许可证、原作者版权声明和必要的上游来源说明。
4. 不重命名 `@aihot/*`、`_aihot`、环境变量和数据库默认名等内部兼容标识，避免破坏包解析、配置兼容和上游同步。

## 验收标准

- GitHub 仓库首页不再把项目展示为 AIHOT。
- README 首屏明确显示 AI支付洞察及其产品目标。
- README 不引用上游 Logo、横幅、线上原站或讨论区。
- 中英文 README 的定位和运行说明一致。
- 类型检查继续通过。
